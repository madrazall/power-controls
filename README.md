# Power Controls - Inventory & Order Management System

A standalone Tauri/Rust application for managing component inventory, orders, and BOMs on internal LANs.

## Project Status

**Current Phase:** Planning & Architecture Design

## Core Features

### MVP (Phase 1) - Inventory Foundation
- [x] Auto-generated unique internal SKUs
- [x] Component inventory database
- [x] Vendor data integration
- [x] Part number mapping to vendors

### Phase 2
- Order simplification interface
- BoM management and generation
- Stock level tracking and alerts

### Phase 3+
- Pricing integration
- Multi-supplier support
- Stock forecasting
- Automated ordering workflows
