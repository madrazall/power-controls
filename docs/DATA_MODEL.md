# Data Model (Revised)\n\n## Overview\n\nThe data model supports:\n- **Physical Inventory:** Items actually in stock (assigned internal SKUs)\n- **Vendor Management:** Vendor profiles with contact info, payment methods, and history\n- **External References:** Manufacturer and vendor part numbers (reference only)\n- **Order Tracking:** Link to previous orders and pricing history\n- **BoM Generation:** Link inventory to product specifications\n\n## Core Entities\n\n### 1. Inventory\n\nOnly physical components in stock are assigned internal SKUs.\n\n```rust\npub struct InventoryItem {\n    pub sku: String,                    // Primary Key: 0000001\n    pub name: String,                   // \"1MΩ Carbon Film 1/4W\"\n    pub description: Option<String>,    // Detailed specs/datasheet link\n    pub category: Option<String>,       // \"Resistor\" (optional, for filtering)\n    pub quantity_on_hand: i32,          // Current stock level\n    pub reorder_point: i32,             // Alert threshold\n    pub status: ItemStatus,             // Active, Discontinued, Obsolete\n    pub location: Option<String>,       // Storage location/bin\n    pub created_at: DateTime,\n    pub updated_at: DateTime,\n    pub retired_at: Option<DateTime>,\n}\n\npub enum ItemStatus {\n    Active,\n    Discontinued,\n    Obsolete,\n    OnBackorder,\n}\n```\n\n**Database Table:**\n```sql\nCREATE TABLE inventory (\n    sku TEXT PRIMARY KEY,\n    name TEXT NOT NULL,\n    description TEXT,\n    category TEXT,\n    quantity_on_hand INTEGER DEFAULT 0,\n    reorder_point INTEGER DEFAULT 0,\n    status TEXT NOT NULL DEFAULT 'active',\n    location TEXT,\n    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,\n    updated_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,\n    retired_at TIMESTAMP\n);\n\nCREATE INDEX idx_inventory_category ON inventory(category);\nCREATE INDEX idx_inventory_status ON inventory(status);\n```\n\n### 2. External Part References\n\nManufacturer, vendor, and datasheet references (stored separately, not required).\n\n```rust\npub struct ExternalPartReference {\n    pub ref_id: String,                 // PK\n    pub sku: String,                    // FK to inventory\n    pub reference_type: RefType,        // \"Manufacturer\", \"Vendor\", \"Datasheet\"\n    pub reference_value: String,        // \"MFR-1234567\" or URL\n    pub notes: Option<String>,\n    pub created_at: DateTime,\n}\n\npub enum RefType {\n    Manufacturer,\n    VendorPartNumber,\n    DatasheetUrl,\n    AlternatePartNumber,\n}\n```\n\n**Database Table:**\n```sql\nCREATE TABLE external_part_references (\n    ref_id TEXT PRIMARY KEY,\n    sku TEXT NOT NULL,\n    reference_type TEXT NOT NULL,      -- \"manufacturer\", \"vendor\", \"datasheet\"\n    reference_value TEXT NOT NULL,\n    notes TEXT,\n    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,\n    FOREIGN KEY (sku) REFERENCES inventory(sku)\n);\n\nCREATE INDEX idx_epr_sku ON external_part_references(sku);\nCREATE INDEX idx_epr_type ON external_part_references(reference_type);\n```\n\n### 3. Vendors (Vendor ID Cards)\n\nComplete vendor profiles with contact info and payment methods.\n\n```rust\npub struct Vendor {\n    pub vendor_id: String,              // Unique identifier\n    pub company_name: String,           // \"Digi-Key\", \"Mouser\", \"Local Supplier\"\n    pub contact_name: Option<String>,   // Primary contact person\n    pub contact_email: Option<String>,  // Email address\n    pub contact_phone: Option<String>,  // Phone number\n    pub address: Option<String>,        // Physical address\n    pub website_url: Option<String>,    // https://www.digikey.com\n    pub payment_methods: Vec<String>,   // [\"Credit Card\", \"Wire Transfer\", \"COD\"]\n    pub lead_time_days: Option<i32>,    // Typical lead time\n    pub notes: Option<String>,          // Any special notes\n    pub is_active: bool,\n    pub created_at: DateTime,\n}\n```\n\n**Database Table:**\n```sql\nCREATE TABLE vendors (\n    vendor_id TEXT PRIMARY KEY,\n    company_name TEXT NOT NULL UNIQUE,\n    contact_name TEXT,\n    contact_email TEXT,\n    contact_phone TEXT,\n    address TEXT,\n    website_url TEXT,\n    payment_methods TEXT,               -- JSON array: [\"Credit Card\", \"Wire Transfer\"]\n    lead_time_days INTEGER,\n    notes TEXT,\n    is_active BOOLEAN DEFAULT TRUE,\n    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,\n    updated_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP\n);\n\nCREATE INDEX idx_vendors_active ON vendors(is_active);\n```\n\n### 4. Vendor Inventory (Available Parts/Materials)\n\nWhat each vendor stocks and current pricing.\n\n```rust\npub struct VendorInventory {\n    pub vendor_inv_id: String,          // PK\n    pub vendor_id: String,              // FK to vendors\n    pub sku: Option<String>,            // FK to inventory (optional - not yet in our system)\n    pub vendor_part_number: String,     // Vendor's part number\n    pub description: Option<String>,    // As listed by vendor\n    pub current_price: Option<f64>,     // Current price\n    pub currency: String,               // \"USD\", \"EUR\", etc.\n    pub minimum_order_qty: i32,         // MOQ\n    pub lead_time_days: Option<i32>,    // Vendor-specific lead time\n    pub last_checked: DateTime,         // When price was last verified\n    pub is_available: bool,             // Currently in stock at vendor\n}\n```\n\n**Database Table:**\n```sql\nCREATE TABLE vendor_inventory (\n    vendor_inv_id TEXT PRIMARY KEY,\n    vendor_id TEXT NOT NULL,\n    sku TEXT,                           -- FK, nullable (not yet in our system)\n    vendor_part_number TEXT NOT NULL,\n    description TEXT,\n    current_price REAL,\n    currency TEXT DEFAULT 'USD',\n    minimum_order_qty INTEGER DEFAULT 1,\n    lead_time_days INTEGER,\n    last_checked TIMESTAMP DEFAULT CURRENT_TIMESTAMP,\n    is_available BOOLEAN DEFAULT TRUE,\n    FOREIGN KEY (vendor_id) REFERENCES vendors(vendor_id),\n    FOREIGN KEY (sku) REFERENCES inventory(sku),\n    UNIQUE(vendor_id, vendor_part_number)\n);\n\nCREATE INDEX idx_vi_vendor ON vendor_inventory(vendor_id);\nCREATE INDEX idx_vi_sku ON vendor_inventory(sku);\n```\n\n### 5. Pricing History\n\nTrack price changes over time per vendor.\n\n```rust\npub struct PriceHistory {\n    pub price_id: String,               // PK\n    pub vendor_inv_id: String,          // FK to vendor_inventory\n    pub price: f64,\n    pub currency: String,\n    pub effective_date: DateTime,\n}\n```\n\n**Database Table:**\n```sql\nCREATE TABLE price_history (\n    price_id TEXT PRIMARY KEY,\n    vendor_inv_id TEXT NOT NULL,\n    price REAL NOT NULL,\n    currency TEXT DEFAULT 'USD',\n    effective_date TIMESTAMP DEFAULT CURRENT_TIMESTAMP,\n    FOREIGN KEY (vendor_inv_id) REFERENCES vendor_inventory(vendor_inv_id)\n);\n\nCREATE INDEX idx_ph_vendor_inv ON price_history(vendor_inv_id);\nCREATE INDEX idx_ph_date ON price_history(effective_date);\n```\n\n### 6. Purchase Orders (Order References)\n\nHistorical orders from vendors for audit trail and pricing reference.\n\n```rust\npub struct PurchaseOrder {\n    pub po_id: String,                  // PK\n    pub vendor_id: String,              // FK to vendors\n    pub po_number: String,              // Vendor's PO number\n    pub order_date: DateTime,\n    pub expected_delivery: Option<DateTime>,\n    pub actual_delivery: Option<DateTime>,\n    pub total_amount: Option<f64>,\n    pub currency: String,\n    pub status: PurchaseOrderStatus,\n    pub notes: Option<String>,\n}\n\npub enum PurchaseOrderStatus {\n    Draft,\n    Submitted,\n    Confirmed,\n    Shipped,\n    Delivered,\n    Cancelled,\n}\n\npub struct PurchaseOrderLineItem {\n    pub po_line_id: String,\n    pub po_id: String,\n    pub vendor_inv_id: String,          // Reference to vendor_inventory\n    pub sku: Option<String>,            // If item is in our system\n    pub quantity: i32,\n    pub unit_price: f64,\n    pub line_total: f64,\n}\n```\n\n**Database Tables:**\n```sql\nCREATE TABLE purchase_orders (\n    po_id TEXT PRIMARY KEY,\n    vendor_id TEXT NOT NULL,\n    po_number TEXT NOT NULL,\n    order_date TIMESTAMP DEFAULT CURRENT_TIMESTAMP,\n    expected_delivery TIMESTAMP,\n    actual_delivery TIMESTAMP,\n    total_amount REAL,\n    currency TEXT DEFAULT 'USD',\n    status TEXT NOT NULL DEFAULT 'draft',\n    notes TEXT,\n    FOREIGN KEY (vendor_id) REFERENCES vendors(vendor_id),\n    UNIQUE(vendor_id, po_number)\n);\n\nCREATE TABLE purchase_order_line_items (\n    po_line_id TEXT PRIMARY KEY,\n    po_id TEXT NOT NULL,\n    vendor_inv_id TEXT NOT NULL,\n    sku TEXT,\n    quantity INTEGER NOT NULL,\n    unit_price REAL NOT NULL,\n    line_total REAL NOT NULL,\n    FOREIGN KEY (po_id) REFERENCES purchase_orders(po_id),\n    FOREIGN KEY (vendor_inv_id) REFERENCES vendor_inventory(vendor_inv_id),\n    FOREIGN KEY (sku) REFERENCES inventory(sku)\n);\n\nCREATE INDEX idx_po_vendor ON purchase_orders(vendor_id);\nCREATE INDEX idx_po_status ON purchase_orders(status);\nCREATE INDEX idx_poli_po ON purchase_order_line_items(po_id);\n```\n\n### 7. Orders (Client Orders - for BoM/Simplification)\n\nClient orders built from inventory.\n\n```rust\npub struct ClientOrder {\n    pub order_id: String,               // PK\n    pub customer_name: String,\n    pub order_date: DateTime,\n    pub required_date: Option<DateTime>,\n    pub status: OrderStatus,\n    pub notes: Option<String>,\n}\n\npub struct OrderLineItem {\n    pub line_item_id: String,\n    pub order_id: String,\n    pub sku: String,                    // FK to inventory\n    pub quantity: i32,\n    pub notes: Option<String>,\n}\n\npub enum OrderStatus {\n    Draft,\n    Submitted,\n    InProgress,\n    Complete,\n    Cancelled,\n}\n```\n\n**Database Tables:**\n```sql\nCREATE TABLE client_orders (\n    order_id TEXT PRIMARY KEY,\n    customer_name TEXT NOT NULL,\n    order_date TIMESTAMP DEFAULT CURRENT_TIMESTAMP,\n    required_date TIMESTAMP,\n    status TEXT NOT NULL DEFAULT 'draft',\n    notes TEXT,\n    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,\n    updated_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP\n);\n\nCREATE TABLE order_line_items (\n    line_item_id TEXT PRIMARY KEY,\n    order_id TEXT NOT NULL,\n    sku TEXT NOT NULL,\n    quantity INTEGER NOT NULL,\n    notes TEXT,\n    FOREIGN KEY (order_id) REFERENCES client_orders(order_id),\n    FOREIGN KEY (sku) REFERENCES inventory(sku)\n);\n\nCREATE INDEX idx_co_status ON client_orders(status);\nCREATE INDEX idx_oli_order ON order_line_items(order_id);\n```\n\n### 8. Constraints\n\n1. **Inventory Items Only in Stock:** SKUs only assigned when physically present\n2. **SKU Immutability:** Never reused, retired items keep their SKUs permanently\n3. **Vendor Part Numbers Optional:** Can add items without knowing vendor part numbers\n4. **Referential Integrity:** All orders and BoMs reference valid SKUs\n5. **Payment Methods Tracked:** Each vendor has payment method preferences\n6. **Pricing Trail:** Historical pricing per vendor for cost analysis\n7. **Order References:** Full PO history for audit and trend analysis\n\n## Workflow: Adding New Component\n\n1. **Component is physically received**\n2. **Create inventory entry:**\n   - Input: name, description, quantity, category (optional)\n   - Backend generates SKU: 0000001\n   - Item now in system\n3. **Add external references (optional):**\n   - Manufacturer part number\n   - Datasheet URL\n   - Vendor-specific part numbers\n4. **Link to vendor inventory (optional):**\n   - Record which vendors stock this part\n   - Add pricing, MOQ, lead time\n5. **Track historical purchases:**\n   - Reference in purchase order history\n"
